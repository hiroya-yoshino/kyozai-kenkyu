# NotebookLM で参考資料を集める手順

## 1. ノートブックを作る（教科ごとに1つ・全部で3つ）

- 「理科（啓林館）」
- 「算数（東京書籍）」
- 「国語（光村図書）」

学年は分けず、その教科の**全学年分**の資料を同じノートブックに入れる（理科は3〜6年、算数・国語は1〜6年）。

## 2. ソースを追加する

「ソースを追加」→「ウェブサイト」に URL を貼る（PDF の URL もそのまま使える）。

**「理科（啓林館）」に入れるもの（3〜6年）**
- 年間指導計画案（標準案・3〜6年が1つのファイル）：https://www.shinko-keirin.co.jp/keirinkan/sho_r6/rika/file/rika_guidance_plan_standard.pdf
- 単元の目標と評価の具体例（6年・確認済み）：https://www.shinko-keirin.co.jp/keirinkan/sho_r6/rika/file/rika_unit_example06.pdf
- 単元の目標と評価の具体例（3〜5年）：6年と同じ形式で、末尾の `06` を `03`・`04`・`05` に変えたURL（未確認。開けなければ啓林館のサイトで「単元の目標と評価の具体例」を探す）
- 小学校学習指導要領解説 理科編（文部科学省のPDF）

**「算数（東京書籍）」「国語（光村図書）」（1〜6年）**：各社のサイトで、学年ごとの「年間指導計画」と「評価規準」の資料を探して追加する。学習指導要領解説（算数編・国語編）も1つずつ入れる。

**ソースの名前に学年を入れる**：追加したソースは、名前を「6年_単元の目標と評価の具体例」のように学年が先頭に来る形に変えておくと、回答の出典を見たときに学年をまちがえにくい。

## 3. 単元ごとに、次の質問を貼りつけて聞く

`［学年］` と `［単元名］` の部分だけ書きかえる。学年を必ず書くこと（1つのノートブックに全学年の資料が入っているため）。

```
［学年］の「［単元名］」について、ソースの資料だけを使って、次の形でまとめてください。ほかの学年の資料はまぜないでください。似た名前の単元がほかの学年にある場合も、指定した学年のものだけを使ってください。資料にないことは「資料に記載なし」と書いてください。

1. 単元名／配当時数（予備の時数）／実施時期
2. 学習指導要領との関連（内容の記号と、ア・イの文）
3. 単元の評価規準（知識・技能／思考・判断・表現／主体的に学習に取り組む態度）
4. 時ごとの表：
   | 時 | 次（まとまり） | 小見出し・問い | 実験・活動の名前 | 評価規準（記号と文・評価方法） |
5. それぞれの情報が、どの資料の何ページにあるか
```

## 4. 結果を Claude に渡す

次のどちらかで渡す。

- **いちばん簡単**：NotebookLM の回答をコピーして、Claude のチャットに貼りつける
- **まとめて渡す**：回答を「メモに保存」し、Google ドキュメントにして Google ドライブに置き、ファイル名を Claude に伝える（Claude は Google ドライブから読める）
