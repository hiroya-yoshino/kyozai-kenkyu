# NotebookLM で参考資料を集める手順

## 1. ノートブックを作る（教科ごとに1つ・全部で3つ）

- 「理科（啓林館）」
- 「算数（東京書籍）」
- 「国語（光村図書）」

学年は分けず、同じ教科の5年・6年の資料をすべて同じノートブックに入れる。

## 2. ソースを追加する

「ソースを追加」→「ウェブサイト」に URL を貼る（PDF の URL もそのまま使える）。

**「理科（啓林館）」に入れるもの**
- 年間指導計画案（標準案・全学年）：https://www.shinko-keirin.co.jp/keirinkan/sho_r6/rika/file/rika_guidance_plan_standard.pdf
- 単元の目標と評価の具体例（6年）：https://www.shinko-keirin.co.jp/keirinkan/sho_r6/rika/file/rika_unit_example06.pdf
- 単元の目標と評価の具体例（5年）：https://www.shinko-keirin.co.jp/keirinkan/sho_r6/rika/file/rika_unit_example05.pdf
- 小学校学習指導要領解説 理科編（文部科学省のPDF）

**算数（東京書籍）・国語（光村図書）**：各社のサイトで「年間指導計画」「評価規準」の資料を探して、同じように追加する。

## 3. 単元ごとに、次の質問を貼りつけて聞く

`［学年］` と `［単元名］` の部分だけ書きかえる。学年を必ず書くこと（1つのノートブックに複数学年の資料が入っているため）。

```
［学年］の「［単元名］」について、ソースの資料だけを使って、次の形でまとめてください。ほかの学年の資料はまぜないでください。資料にないことは「資料に記載なし」と書いてください。

1. 単元名／配当時数（予備の時数）／実施時期
2. 学習指導要領との関連（内容の記号と、ア・イの文）
3. 単元の評価規準（知識・技能／思考・判断・表現／主体的に学習に取り組む態度）
4. 時ごとの表：
   | 時 | 次（まとまり） | 小見出し・問い | 実験・活動の名前 | 評価規準（記号と文・評価方法） |
5. それぞれの情報が、どの資料の何ページにあるか
```

## 4. 結果を Claude に渡す

次のどちらかで渡す。

- **いちばん簡単**：NotebookLM の回答をコピーして、Claude のチャットに貼りつける
- **まとめて渡す**：回答を「メモに保存」し、Google ドキュメントにして Google ドライブに置き、ファイル名を Claude に伝える（Claude は Google ドライブから読める）
